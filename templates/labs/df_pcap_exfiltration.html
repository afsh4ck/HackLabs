Objetivo

Un endpoint muestra un volumen inusual de consultas DNS hacia un dominio externo. Reconstruye los datos exfiltrados a partir de las peticiones DNS capturadas.

Flag: — la flag está oculta en el propio fichero de evidencia; analízalo y valídala en la caja «Validar Flag» al final de esta página.

Inicio rápido

tshark -r dns_traffic.pcap -Y "dns.flags.response==0" -T fields -e dns.qry.name
{% include 'labs/_forensic_questions.html' %}

1 · Por qué funciona

El tráfico DNS casi nunca se inspecciona ni se bloquea, porque es imprescindible para el funcionamiento normal de la red. Un atacante puede abusar de esto: codifica los datos que quiere robar como subdominios de consultas DNS (DNS tunneling / exfiltration) y las envía una a una a un dominio bajo su control — cada consulta parece tráfico DNS legítimo.

2 · Listar las consultas DNS salientes

tshark -r dns_traffic.pcap -Y "dns.flags.response==0" -T fields -e frame.number -e dns.qry.name

Todas comparten el mismo sufijo: exfil.attacker-c2.net — un dominio externo no relacionado con la infraestructura interna.

3 · Extraer los fragmentos codificados

tshark -r dns_traffic.pcap -Y "dns.flags.response==0" -T fields -e dns.qry.name
# 00-484c7b706c34...exfil.attacker-c2.net
# 01-315f7433376337...exfil.attacker-c2.net
# ...

El primer campo de cada subdominio (00-, 01-…) indica el orden del fragmento; el resto, antes del sufijo, es el dato exfiltrado codificado en hexadecimal.

4 · Reconstruir el mensaje

python3 - <<'EOF'
from scapy.all import rdpcap, DNS, DNSQR
pkts = rdpcap('dns_traffic.pcap')
chunks = {}
for p in pkts:
    if p.haslayer(DNS) and p[DNS].qr == 0 and p.haslayer(DNSQR):
        qname = p[DNSQR].qname.decode().rstrip('.')
        idx, chunk = qname.split('.')[0].split('-')
        chunks[int(idx)] = chunk
hexstr = ''.join(chunks[i] for i in sorted(chunks))
print(bytes.fromhex(hexstr).decode())
EOF

Concatenando los fragmentos en orden y decodificando de hexadecimal a texto se reconstruye el dato exfiltrado completo.

Mitigación

  • Monitorizar el tráfico DNS en busca de volumen anómalo de consultas, subdominios largos/aleatorios y dominios de baja reputación (DNS analytics / RPZ).
  • Restringir la resolución DNS a resolvers corporativos autorizados; bloquear DNS-over-HTTPS no gestionado que evite esa inspección.
  • Implementar egress filtering y alertar sobre patrones de tunneling conocidos (herramientas como dnstop, Zeek).

1 · Why it works

DNS traffic is almost never inspected or blocked, because it's essential for normal network operation. An attacker can abuse this: encode the data they want to steal as subdomains of DNS queries (DNS tunneling / exfiltration) and send them one by one to a domain they control — each query looks like legitimate DNS traffic.

2 · List the outbound DNS queries

tshark -r dns_traffic.pcap -Y "dns.flags.response==0" -T fields -e frame.number -e dns.qry.name

They all share the same suffix: exfil.attacker-c2.net — an external domain unrelated to the internal infrastructure.

3 · Extract the encoded fragments

tshark -r dns_traffic.pcap -Y "dns.flags.response==0" -T fields -e dns.qry.name
# 00-484c7b706c34...exfil.attacker-c2.net
# 01-315f7433376337...exfil.attacker-c2.net
# ...

The first field of each subdomain (00-, 01-…) indicates the fragment order; the rest, before the suffix, is the exfiltrated data hex-encoded.

4 · Reconstruct the message

python3 - <<'EOF'
from scapy.all import rdpcap, DNS, DNSQR
pkts = rdpcap('dns_traffic.pcap')
chunks = {}
for p in pkts:
    if p.haslayer(DNS) and p[DNS].qr == 0 and p.haslayer(DNSQR):
        qname = p[DNSQR].qname.decode().rstrip('.')

Concatenating the fragments in order and decoding from hex to text reconstructs the full exfiltrated data.

Mitigation

  • Monitor DNS traffic for anomalous query volume, long/random subdomains and low-reputation domains (DNS analytics / RPZ).
  • Restrict DNS resolution to authorized corporate resolvers; block unmanaged DNS-over-HTTPS that bypasses that inspection.
  • Implement egress filtering and alert on known tunneling patterns (tools like dnstop, Zeek).
