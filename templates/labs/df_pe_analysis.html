Objetivo

Un ejecutable disfrazado de factura llegó por correo. Analiza sus cabeceras PE de forma estática para identificar indicios de comportamiento malicioso.

Flag: — la flag está oculta en el propio fichero de evidencia; analízalo y valídala en la barra lateral.

Aviso

Este ejecutable Windows es inofensivo — se generó específicamente para este laboratorio y solo imprime un mensaje de prueba. No lo ejecutes fuera de una VM aislada; el objetivo del lab es el análisis estático, no la ejecución.

Inicio rápido

file Factura_Pendiente.exe
strings Factura_Pendiente.exe | grep -iE "http|CurrentVersion"

1 · Por qué funciona

El formato PE (Portable Executable) de Windows tiene una estructura de cabeceras bien documentada (DOS header, PE header, tabla de secciones, tabla de imports) que se puede parsear sin ejecutar el binario. Analizar esas cabeceras revela la arquitectura objetivo, las librerías/API que importa (comportamiento potencial) y cualquier cadena de texto embebida — todo ello sin correr ningún riesgo.

2 · Confirmar que es un PE y su arquitectura

file Factura_Pendiente.exe
# Factura_Pendiente.exe: PE32+ executable for MS Windows, x86-64, 18 sections

Un supuesto visor de facturas no debería ser un ejecutable nativo de Windows de 64 bits.

3 · Inspeccionar la cabecera PE con pefile

python3 - <<'EOF'
import pefile
pe = pefile.PE('Factura_Pendiente.exe')
print('Machine:', hex(pe.FILE_HEADER.Machine))   # 0x8664 = x86-64
print('Sections:', [s.Name.decode().strip('\x00') for s in pe.sections])
EOF

También puedes usar objdump -f Factura_Pendiente.exe para ver el mismo campo Machine sin depender de Python.

4 · Extraer cadenas sospechosas

strings Factura_Pendiente.exe | grep -iE "http|CurrentVersion\\\\Run"
# SOFTWARE\Microsoft\Windows\CurrentVersion\Run\InvoiceHelper
# https://update-cdn.attacker-infra.ru/beacon.php

La clave de registro ...CurrentVersion\Run\... es la ruta clásica de persistencia de Windows (ejecución automática al iniciar sesión), y la URL apunta a infraestructura externa de C2 — ninguna de las dos tiene sentido en un "visor de facturas".

5 · Capturar la flag

strings Factura_Pendiente.exe | grep "HL{"
HL{···}

Mitigación

  • Bloquear la ejecución de adjuntos .exe recibidos por correo a nivel de gateway.
  • AppLocker / Windows Defender Application Control para permitir solo binarios firmados y en rutas conocidas.
  • Monitorizar escrituras en claves Run/RunOnce del registro como señal de persistencia (Sysmon Event ID 13).

Herramientas

pefile objdump strings CFF Explorer / PE-bear
